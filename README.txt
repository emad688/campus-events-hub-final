Campus Events Hub
=================

Project Type:
Dynamic university events website using HTML, CSS, and PHP.

Included Pages:
- index.php
- events.php
- event.php
- register.php
- registrations.php
- about.php

Included Features:
- Shared header and footer using require
- Semantic HTML
- Shared external CSS file
- Responsive design
- PHP array as the events data source
- GET parameter on event.php?id=...
- POST handling and server-side validation
- CSV registration storage
- Reading registrations and displaying them in a table
- Contact form validation without sending email
- Error and confirmation messages

How to Run with XAMPP:
1. Install XAMPP.
2. Open the XAMPP Control Panel.
3. Start Apache.
4. Copy the folder "campus-events-hub-complete" into:
   C:\xampp\htdocs\
5. Open the following address in your browser:
   http://localhost/campus-events-hub-complete/index.php
